# Proyectos de Inteligencia Artificial

Portafolio técnico de **Inteligencia Artificial, Machine Learning y Deep Learning en Python**, compuesto por implementaciones reproducibles que exploran desde modelos neuronales clásicos hasta redes multicapa y flujos end-to-end.

Cada proyecto incluye explicación técnica, preparación de datos, entrenamiento, evaluación, visualizaciones y conclusiones. Los notebooks pueden abrirse directamente en **Google Colab** sin instalación local.

## Competencias demostradas

- Diseño de experimentos de Machine Learning reproducibles.
- Preparación, separación y estandarización de datos.
- Clasificación binaria y multiclase.
- Perceptrón y redes neuronales multicapa.
- TensorFlow/Keras y scikit-learn.
- Métricas, matrices de confusión y curvas ROC.
- Visualización de fronteras de decisión.
- Análisis de errores y conclusiones técnicas.
- Uso de Jupyter Notebook y Google Colab.

## Tecnologías

`Python` · `NumPy` · `Pandas` · `Matplotlib` · `scikit-learn` · `TensorFlow` · `Keras` · `Jupyter` · `Google Colab`

## Ejecución

La forma más sencilla de explorar los proyectos es utilizar el botón **Abrir en Colab** de cada notebook. También pueden ejecutarse localmente instalando las dependencias de `requirements.txt`.

```bash
pip install -r requirements.txt
```
